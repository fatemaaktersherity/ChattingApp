# Chatting App

A real-time, room-based chat application built with Node.js, Express and Socket.IO.

## Features

- Real-time messaging between users in the same room
- Enter a name and room name on joining; messages stay within the room
- Online users list for each room
- Share images, videos, audio files and ZIP files (up to 18 MB)
- Click an image to view it full size

## Tech Stack

- Node.js
- Express
- Socket.IO
- HTML, CSS, JavaScript (jQuery)

## Getting Started

1. Clone the repository:

```
   git clone https://github.com/fatemaaktersherity/ChattingApp.git
```

2. Go into the folder:

```
   cd ChattingApp
```

3. Install dependencies:

```
   npm install
```

4. Start the server:

```
   node server.js
```

5. Open your browser and go to http://localhost:1000

To chat with someone, open the app in two tabs, enter different names, and use the same room name in both.
